# Paperwren 1.9.0

## New

- **Hide highlights while reading** (#100): toggle highlights on or off from the Highlights panel so you can read clean pages while keeping your notes open beside them.
- **Settings shortcut**: press `Ctrl+,` (`Cmd+,` on macOS) to open Settings from anywhere.
- **Scrollable desktop tab strip**: tabs shrink cleanly and scroll horizontally with keyboard arrow navigation instead of clipping when many files are open.
- **High-contrast theme support**: full `forced-colors` support for Windows contrast themes, stronger control borders and text contrast across all five themes.

## Large PDFs, storage and Android

- **Stream large PDFs** (#97, #98): large PDFs now read page by page over byte ranges instead of loading the entire file into memory, fixing crashes on 350 MB PDFs and showing the first page much sooner.
- **CamScanner and picture PDF stability** (#94): lowered the phone render cap and deferred heavy signature scans on large files so scanned picture PDFs stay open without restarting the renderer.
- **Lower Android storage usage** (#95): files picked with **Open file** now open directly through Android's persistable URI access instead of duplicating into app storage; managed copies are pruned during long sessions while protecting open files, and removed thumbnails and empty store keys are deleted cleanly.
- **Ephemeral external opens on Android** (#98): PDFs opened from WhatsApp, Gmail or a file manager stay out of Android Recents and return cleanly to the calling app on Back.
- **Rotation and touch fixes** (#94, #99): rotating from landscape to portrait keeps your current page, duplicate native scrollbars are hidden on touch screens, and the edge scrubber ignores accidental thumb grazes while scrolling.

## Speed, memory and reliability

- **No startup flash or window jump**: on desktop, the window opens already placed, sized and coloured in your saved theme.
- **Fixed PDF close memory leak**: closing a PDF releases all page DOM nodes and listeners; hidden tabs release drawn canvases after 10 seconds while keeping your scroll position.
- **Lighter tools and viewers**: Fill & sign, Mark up, Organize pages, Pictures to PDF, Read text (OCR), and Scan release offscreen canvases and bitmaps cleanly; split-each-page and note/mark restores no longer re-parse or rewrite on every item.
- **Faster menus, search and switching**: extracted SVG paper textures out of the entry stylesheet, lazy-loaded secondary screens and tools, narrowed state subscriptions, and cut Find debounce latency.
- **Unsaved-work protection**: every close path (tab X, `Ctrl+W`, Back, window close) asks before dropping unsaved edits in Fill & sign, Mark up, Crop pages, Organize pages, Scan, Notes, or password-protected PDF highlights.
- **Settings navigation fix** (#93): clicking a section in Settings highlights it straight away and keeps lower sections (Updates, Privacy) selected until you scroll manually.
- **Truthful saves and error recovery**: failed writes and deletes keep your data and offer Try again; Undo and stored copies share one lifetime.

## Security and privacy

- **Tighter Android and desktop file boundaries**: Android rejects non-`content://` and self-owned `FileProvider` intents, narrows camera `FileProvider` scope to `Pictures/`, restricts release bridge origins to `tauri.localhost`, and escapes JS line separators.
- **Hardened Rust commands**: gated folder listing and rename to desktop, blocked Windows UNC/device paths and symlink/script-rename escapes, capped store and save payloads, pruned unused Tauri plugin commands, and locked CSP with `frame-src 'none'; media-src 'none'`.
- **Document sanitization and password privacy**: added strict central-directory ZIP-bomb checks before opening DOCX and XLSX files, sanitized DOCX styles/links and spreadsheet links, cleared `PasswordDialog` state on close, and disabled persistent bookmarks on password-protected documents.
