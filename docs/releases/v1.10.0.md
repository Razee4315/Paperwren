# Paperwren 1.10.0

This release focuses on speed, responsiveness, battery life, memory efficiency, and dependency modernization, with no changes to how the app looks or works.

## Faster document opening and smoother navigation

- **Off-thread document hashing**: document mark keys now use native WebCrypto `SHA-512` off the main thread instead of pure-JS hashing over up to 2 MiB on every PDF open.
- **Smarter PDF opening and streaming**: signature scans run on demand when a signature spot is present or an editing tool opens (avoiding eager full-file buffer copies on ordinary PDFs), `CropPages` loads lazily, desktop byte-range reads use 256 KiB chunks, and streamed sample reads wait until page 1 draws.
- **Snappier menus, tabs, Settings, and theme switching**: covered Home and hidden desktop tabs use `content-visibility: hidden` to stay out of style and layout passes while preserving scroll position and bitmaps; removed synchronous `getComputedStyle`, `scrollWidth`, and `scrollIntoView` stalls on menu, dialog, theme, side panel, and Settings open.
- **Smoother Home and spreadsheet scrolling**: promoted Home's scroller to its own compositor layer with a shared `IntersectionObserver` and memoized rows; added strict cell containment, numeric merge keys, and a two-level text width cache to the spreadsheet viewer.

## Lower idle power and memory

- **Zero minimized file-check wakeups on Windows**: hiding the child webview on minimize (including undecorated Windows iconic sizes) and subscribing to native window focus stops `plugin:fs|stat` polling while minimized or unfocused, cutting minimized PDF idle wakeups to 0/min.
- **Lighter multi-tab footprint**: closed `Sheet`/`Dialog` subtrees are gated behind their open flag, Office/EXIF metadata parses on demand when File details opens, and window resize queries settle cleanly after drags end.

## Toolchain and dependency updates

- Updated Tauri (`2.12.7`, `tao 0.37.3`, `wry 0.57.3`, `plugin-fs 2.7.1`, `plugin-dialog 2.8.4`, `plugin-updater 2.14.1`) and compatible JS/Rust dependencies (`marked`, `highlight.js`, `dompurify`, `katex`, `docx-preview`).
- Upgraded the frontend toolchain to TypeScript 7, Vite 8 (keeping `chrome89` compatibility), and Vitest 5, resolving all 8 prior `npm audit` vulnerabilities.
