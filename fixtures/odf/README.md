# OpenDocument test files

Real `.odt` and `.odp` files used by the OpenDocument tests. They come
from the LibreOffice project's unit-test data
(https://github.com/LibreOffice/core, `sd/qa/unit/data/odp` and
`sw/qa/extras/odf*/data`), distributed under the Mozilla Public
License 2.0.

Test fixtures only: nothing here ships in the app.
